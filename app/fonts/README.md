# Fonts

**Hanken Grotesk** (variable, weights 100–900), the typeface of the CIS-MAP brand guide (edition 3.1).
Designed by Alfredo Marco Pradil (Hanken Design Co.), published on Google Fonts under the
**SIL Open Font License, Version 1.1**, which allows it to be bundled and redistributed with the app:
<https://openfontlicense.org> (licence text) · <https://fonts.google.com/specimen/Hanken+Grotesk>.

The two files are Google Fonts' own subsets, taken from the brand guide's offline copy:

| File | Characters |
|---|---|
| `hanken-grotesk-latin.woff2` | Basic Latin and Latin-1, punctuation, ↑ ↓ |
| `hanken-grotesk-latin-ext.woff2` | Latin Extended |

Chinese is set in the phone's own font (PingFang SC on Apple devices, Noto Sans SC or Microsoft YaHei
elsewhere), as the brand guide says. The CIS licensed typeface (Theinhardt) is not used in the app.
